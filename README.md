# Mock Location (Android)
## Get the APK without Android Studio
1. Create a free GitHub account, make a new repository, upload ALL files of this folder (keep the .github folder).
2. Open the Actions tab, wait for "Build APK" to finish (about 3-5 minutes).
3. Open the finished run, download the artifact MockLocation-apk, unzip it, send app-debug.apk to your phone and install it.
## Use
Settings > About phone > tap Build number 7 times. Then Developer options > Select mock location app > Mock Location.
Open the app, allow permissions, tap the map, press Start.
Route mode: turn it on, tap several points, set speed, press Start.
